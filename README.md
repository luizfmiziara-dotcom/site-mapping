# 🗼 Mapa de Proximidade de Sites

Aplicação Streamlit para análise de proximidade entre sites ATC e competidores.

## Funcionalidades

- Pesquisa por ID ou nome do site
- Busca por coordenadas de oportunidade
- Visualização em mapa satélite
- Exibição de competidores próximos
- Exibição de outros sites ATC
- Radius de busca de 500 m a 3 km
- Download da imagem em PNG
- Cópia da imagem para área de transferência

## Tecnologias

- Python
- Streamlit
- Pandas
- Numpy
- Scikit-Learn
- Matplotlib
- Contextily
- PyProj
- Supabase
